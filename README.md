# Колоквіум з алгебри та геометрії

Статичний сайт у стилі наданого HTML-зразка: клітинка, блакитні заголовки-наліпки, скелети відповідей, повні доведення, тренувальні картки та таймер на 7 хвилин.

Усі 43 питання замінено матеріалом із `kol1.jpeg`, `kol2.jpeg`, `kol4.jpeg`. Зображення доступні за посиланнями внизу сторінки. Означення, нумерацію та доведення адаптовано за наданим PDF лекцій «ПМ+КН+ІПЗ+АКІТР Алгебра та геометрія 26-27». Приклади Nivel 2 — авторські побудови, перевірені за лекційними означеннями. Повна відповідність карток розділам наведена в `LECTURE_ALIGNMENT.md`.

## Швидкий запуск

Відкрий `index.html` у браузері. Збирання, npm, серверна частина, API-ключі та платні сервіси не потрібні. Шрифти та MathJax зберігаються локально.

Для локального сервера з папки цього сайту:

```sh
python3 -m http.server 4173
```

Відкрий `http://localhost:4173/`. Щоб зупинити сервер, натисни Ctrl+C.

## Безкоштовна публікація на GitHub Pages

1. Створи **публічний** репозиторій у GitHub, наприклад `algebra-colloquium`.
2. Завантаж **вміст цієї папки** у корінь репозиторію: `index.html` має лежати безпосередньо в корені, поруч із `styles.css`, `app.js`, `variant.js`, `questions.js`, `assets/` та трьома JPEG. Якщо користуєшся ZIP, спершу розпакуй його. Сам ZIP завантажувати замість файлів не потрібно.
3. У репозиторії відкрий **Settings → Pages**.
4. У **Build and deployment → Source** обери **Deploy from a branch**.
5. Обери гілку **main**, папку **/ (root)** і натисни **Save**.
6. Дочекайся публікації. Посилання з’явиться на цій же сторінці: `https://YOUR-USERNAME.github.io/algebra-colloquium/`.

Файл `.nojekyll` вимикає непотрібну обробку Jekyll. Усі шляхи відносні, тому сайт працює і в підпапці репозиторію. Якщо завантажуєш через Git, додай також цей файл; через вебінтерфейс можна створити порожній `.nojekyll` окремо.

Публічні репозиторії підтримують GitHub Pages на GitHub Free. [Офіційна інструкція GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).

## Калькулятор

Для додатних цілих:

```js
modStar(a, b) = ((a - 1) % b) + 1
```

Для `k` від 1 до 100:

- Nivel 1: `modStar(k, 23)`, `modStar(k + 12, 23)`.
- Nivel 2: `modStar(k, 9)`, `modStar(k + 5, 9)`.
- Nivel 3: `modStar(k, 7)`.
- Nivel 4: `modStar(k, 4)`.

**У вихідному тексті є арифметична помилка:** для `k = 49` значення Nivel 4 дорівнює **1**, а не 3: `49 = 12 × 4 + 1`. Тому правильний результат: **N1: 3, 15; N2: 4, 9; N3: 7; N4: 1**. Сайт використовує саме задані формули.

Калькулятор обирає шість карток і підставляє параметри в усі приклади Nivel 2. «Розрахувати» не запускає таймер; «Розрахувати + старт 7 хв» запускає його й відкриває скелети. Випадковий варіант обирає одне `k` та застосовує ті самі правила.

У заголовку «Скелети мого варіанту» поруч із кнопкою друку є кнопка «Показати повні відповіді», яка розгортає обрані доведення N3 та N4 разом. Повторне натискання згортає їх.

У кожній картці Nivel 3 та Nivel 4 є перемикач «Показати повну відповідь» / «Сховати повну відповідь». Він доступний і в загальному списку, і в режимі «7 хвилин». Спочатку доведення згорнуті. У тренуванні перемикач з’являється після відкриття відповіді.

Ручна зміна номерів не змінює `k`: значення N2 залишаються для введеного номера, про що повідомляє сторінка. Вибір і прогрес тренування зберігаються в localStorage цього браузера. Таймер скидається після перезавантаження сторінки.

## Редагування

- `index.html` — структура сторінки та пояснення правил.
- `styles.css` — оригінальний стиль із доповненнями для калькулятора, друку та мобільного екрана.
- `questions.js` — всі питання, скелети, відповіді й зауваження; поле `lectureRef` указує підставу в конспекті.
- `LECTURE_ALIGNMENT.md` — відповідність усіх 43 карток розділам лекцій та опис узгоджених позначень.
- `variant.js` — чисті функції розрахунку номерів і параметрів.
- `app.js` — інтерфейс, числові приклади N2, таймер, тренування, тема й збереження прогресу.
- `assets/` — локальні шрифти, MathJax, іконка та ліцензії.

У текстах `questions.js` формули пишуться між `\\(` і `\\)` або `\\[` і `\\]`. Це JavaScript-рядки: зворотну скісну риску треба подвоїти. Символ `<` у математичних нерівностях записуй як `&lt;`, щоб браузер не сприймав його як HTML-тег.

**N1·18–19:** використано точну нумерацію 1–6 із PDF: обернена до cA; обернена до AB; E⁻¹=E; обернені до елементарних матриць; збіг лівої та правої обернених; необоротність матриці з нульовим рядком. **Парабола:** як у лекції, x²=2py, фокус (0,p/2), директриса y=−p/2. **Лінійні комбінації:** наведено всі чотири лекційні властивості. У N2·7 фразу «немає обернених» пояснено як відсутність взаємно обернених пар серед множників; кожна елементарна матриця сама є оборотною.

## Перевірка

За наявності Node.js 18+:

```sh
node tests/variant.test.cjs
```

Перевіряються всі 100 варіантів, правило нульового залишку, некоректний ввід, нумерація 43 питань і коректність числових конструкцій Nivel 2. Тест не потребує залежностей.

Ліцензії сторонніх ресурсів: `assets/licenses/`. MathJax взято з наданого HTML-файлу; шрифти Golos Text, Neucha, JetBrains Mono — з Google Fonts. Оригінальний HTML та зображення залишено в початковій папці; ZIP містить лише готовий сайт і його перевірки.

Лекційний PDF використано як локальне джерело; до публічного ZIP його не додано. У формулах виправлено очевидні друкарські огріхи конспекту, збережено його нумерацію та структуру доведень.
